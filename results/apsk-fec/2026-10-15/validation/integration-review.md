No blocking correctness finding. This was a read-only source, linked ELF, arena, ring ownership, shutdown, capture and PIO review. No USB access or SDK build was performed. All 107 archived firmware source hashes, all 112 snapshot-manifest entries and the source tar match; current firmware has zero differences from /tmp/yapogee-apsk-fec-snapshot-4. The iqbench UF2 SHA256 is 8fbbb2d05aeffebd5517ff10ad44ec6cec2445eee1172ee1939d1964b33c7da1.

The borrowed context is correctly aligned: cap_buf is 0x20051fac (4 modulo 8), so the 248-byte live_t rounds upward to 0x2005dfb0. It ends at 0x2005e0a8, leaving 7,940 bytes inside the existing array. Output, finite capture and context do not overlap. Mode-specific LUT/Gold regions, PV emulator, temporary offset keys, native input and PV slots remain disjoint. No new BSS arena is introduced. Absolute ranges for both ELF targets are in source-elf-memory.json.

Core 1 publishes completed native words before waiting, then reserves 64 words against the oldest retained index. Core 0 releases input only after shaping and retains two native words for 16APSK or four for 32APSK, preserving eight symbols across ring and PLFRAME boundaries. Final bulk mapper paths stop at both the next 64-word credit boundary and ring end; n/carry is committed consistently on callback cancellation. An independent mapper review found no blocker. Native partial words survive frames without padding. Shutdown stops output before joining the encoder; SPI remains alive until its consumer quiesces, then stops before arena restoration. The inclusive partial-frame host bound is appropriate when cancellation occurs in the frame-end publication callback.

The capture boundary uses the exact integer ceiling of hz*ms/(8000*cpw*frame_symbols), then converts that frame index to a global symbol boundary. The timer triggers one 1024-symbol block early, removing the old late DMA-observation quantization. Arithmetic is safe throughout the admitted parameter range. This trigger alone is not a coverage proof: the host still requires all 8,192 observations to match a bounded finite reference and span the full 90-symbol PLHEADER. A late window therefore fails qualification. For CPW 9–32, four PIO ticks at an exact cpw/4 divider produce integer cpw-clock bus periods; capture retains divider 1. Existing actual-opcode tests cover all 256 fractional phases. External pad setup/hold is unmeasured.

Generated SRAM offset assembly differs from the original source only in section and exported symbol. All three linked functions remain 162 bytes.
